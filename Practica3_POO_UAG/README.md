# Prácticas de Programación Orientada a Objetos

> Alumno: Daniel Ernesto Garrido Sánchez · Matrícula: 5211038 · Ing. de Software y Minería de Datos

## Resumen de prácticas
- **Práctica 1 — Abstracción y Encapsulamiento:** ejercicios de fundamentos de C++, sentencias de control, procesamiento de cadenas y creación e interacción de objetos.
- **Práctica 2 — Herencia y Polimorfismo:** jerarquías de vehículos, polimorfismo, sobrecarga de operadores y métodos, y colecciones recorridas con iteradores.
- **Práctica 3 — Excepciones, Archivos y BD:** validación con excepciones propias, archivos de texto, conexión a SQLite, uso de la librería externa nlohmann/json e integración de archivo + base de datos con manejo de errores.
